# Нечёткая модель дифференциальной диагностики ОРЗ

Программа к курсовому проекту «Применение нечёткой логики для дифференциальной диагностики острых респираторных заболеваний по совокупности симптомов».

ОРВИ, грипп и COVID-19 описываются эталонными нечёткими множествами (средняя выраженность признаков у больных), острый тонзиллит и аллергический ринит описываются нечёткими правилами по клиническим рекомендациям. Модель сравнивает описание пациента с эталонами по евклидовой мере близости, проверяет правила и выдаёт предварительный диагноз, заболевания, которые нельзя исключить, подозрение по правилу или сообщение о нетипичной картине.

Онлайн-версия: https://fuzzy-ari-diagnosis.streamlit.app/

## Запуск

Нужен Python 3.12.

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\streamlit run app.py
```

Для расчётов глав 2 и 3 и построения рисунков нужны дополнительные библиотеки:

```
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python compute_all.py
.venv\Scripts\python make_figures.py
```

`compute_all.py` печатает все числа, приведённые в работе, и сохраняет их в `results.json`.

## Состав

| Файл | Назначение |
|---|---|
| `model.py` | признаки, шкала термов, величины κ, эталоны, правила, меры близости, алгоритм принятия решения |
| `app.py` | веб-интерфейс (Streamlit) |
| `virome.py`, `data/virome` | данные проекта Virome of Manhattan: эпизоды ОРВИ, оценка κ и эталона ОРВИ, проверка на взрослых |
| `textbook_cases.py`, `data/textbook_cases.json` | ситуационные задачи и их проверка |
| `carbon.py` | загрузка данных Carbon Health |
| `compute_all.py`, `make_figures.py` | все расчёты и рисунки глав 2 и 3 |
| `make_screenshots.py` | снимки экрана интерфейса для работы |

## Данные

- **Virome of Manhattan** (Galanti et al., PLOS Biology, 2024): метаданные мазков и дневники симптомов лежат в `data/virome`.
- **Carbon Health** в репозиторий не включены. Их нужно скачать из https://github.com/mdcollab/covidclinicaldata (папка `data`) и положить CSV-файлы в `data/carbonhealth`.
