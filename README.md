# Нечёткая модель дифференциальной диагностики ОРЗ

Программа к курсовому проекту «Применение нечёткой логики для дифференциальной диагностики острых респираторных заболеваний по совокупности симптомов».

Модель сравнивает нечёткое описание пациента с эталонами пяти заболеваний (ОРВИ, грипп, COVID-19, острый тонзиллит, аллергический ринит) по евклидовой мере близости и выдаёт предварительный диагноз, заболевания, которые нельзя исключить, или сообщение о нетипичной картине.

## Запуск

Нужен Python 3.12.

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\streamlit run app.py
```

## Состав

| Файл | Назначение |
|---|---|
| `model.py` | признаки, шкала термов, эталоны, меры близости, правила, алгоритм принятия решения |
| `app.py` | веб-интерфейс (Streamlit) |
| `evaluation.py` | показатели качества, доверительные интервалы, анализ чувствительности |
| `textbook_cases.py`, `data/textbook_cases.json` | ситуационные задачи и их проверка (п. 3.3) |
| `carbon.py`, `analyze_carbon.py` | проверка на данных реальных пациентов (п. 3.4) |
| `compute_ch3.py`, `compute_euclid.py`, `make_surfaces.py` | расчёты и рисунки для п. 3.5 |

## Данные Carbon Health

Данные в репозиторий не включены. Их нужно скачать из репозитория
https://github.com/mdcollab/covidclinicaldata (папка `data`) и положить CSV-файлы в `data/carbonhealth`.
